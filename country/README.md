# country

ISO 3166-1 alpha-2 country codes. `Code` normalizes the ways people and other systems write a country (`"de"`, `" AT "`, `"SUI"`, `"Österreich"`, `"Germany"`) to the canonical upper-case code, reports EU membership and English names, and reads and writes SQL and JSON. Use `Code` for required countries and `NullableCode` for optional ones.

    import "github.com/domonda/go-types/country"

## Code

```go
type Code string //#enum

const Invalid Code = "" //#exclude
```

`Invalid` is marked `//#exclude` so that go-enum leaves it out of `Enums()`.

### Constants

The package declares 251 `Code` constants named after their code (`country.DE`, `country.AT`, `country.US`, ...): the 249 ISO 3166-1 alpha-2 codes plus two non-ISO codes:

- `EL`: Greece as the EU writes it, used as the prefix of Greek VAT IDs. `GR` is the ISO code. Both are valid, both are in the EU and both are named `"Greece"`.
- `XK`: Kosovo, a user-assigned code in common use.

List them with the go-enum generated methods. Both return the codes in declaration order, which is close to alphabetical by English name:

```go
codes := country.Code("").Enums()        // []country.Code{country.AF, country.AX, country.AL, ...}
names := country.Code("").EnumStrings()  // []string{"AF", "AX", "AL", ...}
```

### Functions and methods

| Identifier                     | Description                                        |
|--------------------------------|----------------------------------------------------|
| `ParseCode(str)`               | Canonical code from a code, an `AltCodes` key or an English country name, see below. |
| `Normalized()`                 | Trims whitespace, upper-cases and looks the result up in the ISO table, then in `AltCodes`. On failure returns the input unchanged and an error. |
| `Valid()`                      | True if `Normalized()` succeeds.                   |
| `Validate()`                   | The error of `Normalized()`, which quotes the input, or nil. |
| `ValidAndNormalized()`         | True only if the code is valid and already canonical. |
| `IsEU()`                       | True for the 27 EU member states and `EL`. Normalizes first; false if invalid. |
| `EnglishName()`                | English name like `"Germany"`. Normalizes first; `""` if invalid. |
| `String()`                     | Normalized code, or the raw string if invalid.     |
| `Nullable()`                   | Plain conversion to `NullableCode`, so `Invalid` becomes `Null`. |
| `ScanString(source, validate)` | Assigns the normalized `source`. If that fails, returns the error when `validate` is true, else assigns `source` as is. |
| `Enums()`, `EnumStrings()`     | All 251 codes, generated by go-enum.               |

Implements: `fmt.Stringer`, `database/sql.Scanner`, `database/sql/driver.Valuer`, `json.Marshaler` (no `UnmarshalJSON`), `encoding.TextMarshaler`, `strfmt.Scannable`, `types.NormalizableValidator[Code]` and `JSONSchema()` (`{"type":"string","pattern":"^[A-Z]{2}$"}`).

`Valid`, `Validate` and `String` are hand-written and carry a `// #custom` marker, so go-enum keeps them instead of generating strict exact-match versions.

### ParseCode

`ParseCode(str)` tries the cheapest interpretation first:

1. A canonical code (`"DE"`) is returned as is.
2. Anything `Normalized` accepts: case and whitespace variants and `AltCodes` keys (`"d"`, `" AUT "`, `"SUI"`, `"Deutschland"`, `"Österreich"`).
3. An English country name from the package table, matched case-insensitively (`"Germany"`, `"united kingdom"`, `"Czech Republic"`). `"Greece"` always gives `GR`, never `EL`.

On failure it returns the input unchanged and the error of `Normalized`.

### AltCodes

```go
var AltCodes map[string]Code
```

Alternative spellings that `Normalized` (and so `Valid`, `Validate`, `ParseCode`, `IsEU` and `EnglishName`) accepts. Keys are upper case, because the input is upper-cased before the lookup:

- the three-letter codes `"AUT"`, `"DEU"` and `"SUI"`,
- the letters `"A"`, `"B"`, `"D"`, `"E"`, `"F"`, `"G"`, `"I"`, `"J"`, `"S"` for AT, BR, DE, ES, FR, GB, IT, JP, SE,
- German names of European countries, like `"DEUTSCHLAND"`, `"ÖSTERREICH"`, `"OESTERREICH"`, `"SCHWEIZ"`, `"VEREINIGTES KÖNIGREICH"`, `"KOSOVO"`.

`AltCodes` is an exported, mutable map. Changing it changes normalization for the whole process and is not safe while other goroutines normalize codes.

## NullableCode

```go
type NullableCode string

const Null NullableCode = ""
```

`NullableCode` is `Code` where `Null` and whitespace-only strings are a valid null value.

| Method                         | Description                                        |
|--------------------------------|----------------------------------------------------|
| `Normalized()`                 | `Null` for empty or whitespace-only input, otherwise like `Code`. |
| `NormalizedWithAltCodes()`     | Same result as `Normalized`, which already consults `AltCodes`. |
| `NormalizedOrNull()`           | Normalized code, or `Null` if invalid.             |
| `Valid()`, `Validate()`        | Null is valid, otherwise like `Code`.              |
| `ValidAndNotNull()`            | Valid and not null.                                |
| `ValidAndNormalized()`         | True for `Null` and for a canonical code.          |
| `IsNull()`                     | True for `""` and whitespace-only strings.         |
| `IsNotNull()`                  | `!IsNull()`.                                       |
| `Get()`                        | The `Code`; panics if null.                        |
| `GetOr(defaultCode)`           | The `Code`, or `defaultCode` if null.              |
| `Set(code)`, `SetNull()`       | Assign a `Code` or `Null`.                         |
| `String()`                     | `""` if null, else the normalized code or the raw string. |
| `StringOr(defaultString)`      | Normalized code, or `defaultString` if null or invalid. |
| `IsEU()`, `EnglishName()`      | As for `Code`.                                     |
| `ScanString(source, validate)` | `""`, whitespace only, `"NULL"`, `"null"` and `"nil"` set `Null`; otherwise like `Code`. |

Implements: `fmt.Stringer`, `database/sql.Scanner`, `database/sql/driver.Valuer`, `json.Marshaler`, `json.Unmarshaler`, `encoding.TextMarshaler`, `strfmt.Scannable`, `nullable.NullSetable[Code]` and `JSONSchema()` (the `Code` pattern or null).

## Serialization

| Value                                    | SQL `Value()`    | JSON (`json.Marshal`) | `String()`, `MarshalText` |
|------------------------------------------|------------------|-----------------------|---------------------------|
| `Code("")` (`Invalid`)                   | `NULL`           | `""`                  | `""`                      |
| `Code("de")`, `Code("Deutschland")`      | `"DE"`           | `"DE"`                | `"DE"`                    |
| `Code("xx")` (invalid)                   | `"xx"`, no error | `"xx"`, no error      | `"xx"`                    |
| `Code("  ")`                             | `"  "`           | `"  "`                | `"  "`                    |
| `NullableCode` `Null` or whitespace only | `NULL`           | `null`                | `""`                      |
| `NullableCode("de")`                     | `"DE"`           | `"DE"`                | `"DE"`                    |
| `NullableCode("xx")` (invalid)           | `"xx"`, no error | `"xx"`, no error      | `"xx"`                    |

| Input                          | `Code`                                  | `NullableCode`       |
|--------------------------------|-----------------------------------------|----------------------|
| `Scan(nil)`                    | `Invalid`                               | `Null`               |
| `Scan(string)`, `Scan([]byte)` | stored as is, not normalized or checked | same                 |
| `Scan` of other types          | error                                   | error                |
| JSON string                    | stored as is, not normalized or checked | same                 |
| JSON `null`                    | field left unchanged                    | `Null`               |
| other JSON values              | error                                   | error                |

Output is normalized, input is not: a value read with `Scan` or `json.Unmarshal` keeps its spelling until you call `Normalized`, but it is written back canonical.

## Gotchas

- **Valid normalizes.** `Code("de").Valid()`, `Code("SUI").Valid()` and `Code("Österreich").Valid()` are all true. Use `ValidAndNormalized` to require the canonical form, or store `Normalized()`.
- **`Normalized` does not know English names.** `Code("Germany").Valid()` is false; `ParseCode("Germany")` returns `DE`.
- **English names must match the table exactly** (apart from case and surrounding whitespace). `"Czech Republic"` works, `"Czechia"` does not; Bolivia is `"Bolivia, Plurinational State of"`, so `"Bolivia"` fails.
- **Few three-letter codes.** Only `"AUT"`, `"DEU"` and `"SUI"` are known. `"USA"`, `"GBR"` and `"CHE"` fail.
- **EL and GR are different codes.** Both are valid EU members named Greece, but `Code("EL") != Code("GR")` and `Normalized` does not map one to the other. Greek VAT IDs (`vat.ID`) report `EL`. Map it yourself if you need ISO codes only: `if c == country.EL { c = country.GR }`.
- **XK is not an ISO code.** Other systems may reject it.
- **Invalid values are written without error.** `Value` and `MarshalJSON` write an invalid code unchanged. Validate before writing.
- **Whitespace.** `NullableCode("  ")` is null (SQL NULL, JSON `null`), but `Code("  ")` is invalid and `Value` writes `"  "`.

## Examples

Normalize free-form input:

```go
package main

import (
	"fmt"

	"github.com/domonda/go-types/country"
)

func main() {
	for _, s := range []string{"at", " DE ", "SUI", "Österreich", "Germany", "Atlantis"} {
		c, err := country.ParseCode(s)
		fmt.Println(c, err)
	}

	c := country.Code("el")
	fmt.Println(c.Valid(), c.ValidAndNormalized(), c.IsEU(), c.EnglishName())
	fmt.Println(len(c.Enums()), c.EnumStrings()[:3])

	// Output:
	// AT <nil>
	// DE <nil>
	// CH <nil>
	// AT <nil>
	// DE <nil>
	// Atlantis invalid country.Code: 'Atlantis'
	// true false true Greece
	// 251 [AF AX AL]
}
```

Store required and optional countries:

```go
package main

import (
	"encoding/json"
	"fmt"

	"github.com/domonda/go-types/country"
)

type Address struct {
	Country country.Code         `json:"country"`
	Billing country.NullableCode `json:"billing"`
}

func main() {
	b, _ := json.Marshal(Address{Country: "de", Billing: "  "})
	fmt.Println(string(b))

	v, _ := country.Code("at").Value()
	fmt.Println(v)
	v, _ = country.Null.Value()
	fmt.Println(v)

	// Output:
	// {"country":"DE","billing":null}
	// AT
	// <nil>
}
```

## Adding a country code

1. Add the constant to the `const` block in `country/code.go`: `XX Code = "XX" // Name`.
2. Add `XX: "Name"` to `countryMap` in `country/data.go`. `TestCode_EnumsMatchCountryMap` and `TestCode_EnglishName` fail if the two lists differ. If it applies, also add the code to `euCountries`, alternative spellings to `AltCodes`, and a VAT format to `vat/formats.go`.
3. Run `./run-go-enum.sh` from the repository root to regenerate `Enums()` and `EnumStrings()`, then `go test ./...`.
4. CI runs `go-enum -validate` and fails if the generated methods are stale.

See [Add an enum code](../docs/howto-add-an-enum-code.md) for the full steps.
